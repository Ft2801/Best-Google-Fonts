# Contributing to Best Google Fonts

Contributions, corrections, and accessibility improvements are welcome.

## Guidelines

- Keep the website dependency-free and build-free.
- Use semantic HTML, modern CSS, and vanilla JavaScript.
- Preserve the single-file website architecture in `index.html`.
- Keep user-facing text in English.
- Verify historical claims before changing font descriptions.
- Preserve keyboard access and responsive behavior.
- Do not add analytics, advertising, or tracking.

## Testing

Before submitting a pull request, verify:

- The page loads without console errors.
- All font bundles load successfully.
- Editable specimens and accordion controls work.
- Variable axes update the correct specimen.
- Theme switching works.
- Desktop and mobile navigation work.
- The desktop container keeps 8rem on each side at 1024px and above.
