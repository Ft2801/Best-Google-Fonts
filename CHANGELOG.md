# Changelog

## Version 1.1.0 - 2026-07-31

### Changed

- Moved Gruppo from the Sans Serif chapter to the Display and Other chapter (it is a decorative display face).
- Moved Hepta Slab from the Monospace and Code Style chapter to the Serif chapter (it is a slab-serif typeface, not a monospace).
- Rewrote the Hepta Slab description to fit its new Serif context.

### Added

- Five new font families, each placed in the correct chapter and in correct alphabetical order:
  - Fira Sans (Sans Serif, between DM Sans and Geist)
  - Domine (Serif, between Crimson Text and Gelasio)
  - Fira Code (Monospace and Code Style, between Datatype and Geist Mono)
  - Great Vibes (Fancy and Handwritten, between Gwendolyn and Imperial Script)
  - Anton (Display and Other, between Anta and Asset)
- Updated inline chapter indices, the CSS @import URL list, the font-data JSON, the JSON-LD ItemList, and SEO metadata to reflect 135 documented families.

## Version 1.0.0 - 2026-07-27

### Added

- Initial public version of Best Google Fonts.
- 130 documented font families across five chapters.
- Editable specimens and capability-aware controls.
- Upfront font loading with progress feedback.
- Responsive navigation and chapter menu.
- Light and dark themes.
- Google Fonts links for every family.
- SEO metadata, social preview, sitemap, robots file, web manifest, and favicon set.
- Branch-based GitHub Pages support through `.nojekyll`.
