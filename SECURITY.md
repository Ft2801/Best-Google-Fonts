# Security Policy

Best Google Fonts is a static website with no backend, authentication system, database, or server-side code.

## Reporting a security issue

Do not open a public issue for a suspected vulnerability.

Report security concerns privately through GitHub Security Advisories:

[https://github.com/Ft2801/Best-Google-Fonts/security/advisories/new](https://github.com/Ft2801/Best-Google-Fonts/security/advisories/new)

Include a description, reproduction steps, the affected browser or environment, and the potential impact.

The latest version available on the `main` branch is the only supported version.
